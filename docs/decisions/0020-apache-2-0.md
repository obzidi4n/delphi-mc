# 0020 — Apache License 2.0

**Status:** accepted · 2026-11-26

## Context

DelphiMC is self-hosted software published as source. The license must let the target
operator — and a small hosting business built on it — run it commercially, modify it, and
redistribute their changes, while keeping contributions safe to accept. MIT is simpler but
grants no patent license and no trademark clause. AGPL would deter the v1.0 user, who may
modify and resell a setup, and adds a compliance surface a single operator will not audit.

## Decision

The repository is licensed under the **Apache License, Version 2.0**. [`LICENSE`](../../LICENSE)
holds the canonical, unmodified text (sha256 `cfc7749b…`). Contributions are inbound under
§5; no CLA is required. There is no `NOTICE` file yet.

## Consequences

- Commercial use, modification, and redistribution are allowed, including closed-source
  derivatives. The AGPL's hosted-service protection is deliberately not taken.
- Contributors grant an express patent license (§3), with patent retaliation.
- The name and logo are **not** licensed (§6): nobody may imply endorsement or ship a
  rebranded "DelphiMC".
- Third-party assets keep their own licenses: PaperMC docs (the embedded corpus), plugin jars
  (downloaded, never redistributed), and the bridge plugin's dependencies. Attribution is
  checked where each enters the build.
- Add a `NOTICE` with a copyright-holder line before distributing binaries if a specific
  holder should be named; nothing requires one today.
- **Forbidden:** relicensing the project under a different license without a new ADR that
  supersedes this one; shipping third-party assets under Apache-2.0 terms they do not carry.
